# TraWiz-style Itinerary Builder

A responsive itinerary proposal prototype based on the `/create-itinerary` flow.

## Features

- AI itinerary builder with prompt or file upload
- Manual itinerary proposal builder
- Lead assignment
- Land package quote options
- Static/branding pages and signature setup
- Loading, success and validation states

## Run locally

```bash
python -m http.server 4173
```

Open `http://127.0.0.1:4173`.
